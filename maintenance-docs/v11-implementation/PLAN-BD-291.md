2. **Coder (RW, fresh per commit, `isolation:"worktree"`):** fuses `cd <WS> && …` into every Bash call; edits via absolute `<WS>/…` paths; verifies regime at start (pwd/HEAD vs injected SHA); runs the §-specific gate INSIDE `<WS>`; emits the coder PREFLIGHT line; writes IMPL-REPORT to its handoff dir; NO patch on return.
