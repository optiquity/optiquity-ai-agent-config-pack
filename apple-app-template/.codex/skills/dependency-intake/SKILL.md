---
name: dependency-intake
description: Use before adding a package, SDK, third-party UI framework, or external API wrapper.
---

Evaluate:

1. Is there a native Apple alternative?
2. Is the dependency available through SPM?
3. What are the maintenance, license, security, and lock-in risks?
4. Does it force an undesirable architecture or interop model?
5. What is the rollback plan?

Return a recommendation, alternatives, and integration risks.
