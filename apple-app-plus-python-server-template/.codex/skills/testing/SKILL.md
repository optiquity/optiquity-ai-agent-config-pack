---
name: testing
description: Use when deciding how to verify behavior or when designing unit, integration, UI, or end-to-end tests.
---

1. Identify the behavior that needs confidence.
2. Prefer the cheapest test that proves the requirement.
3. Recommend unit and integration tests before UI automation where possible.
4. Recommend XCUITest for native Apple UI coverage.
5. Mention Maestro or Appium MCP only when the extra setup is justified.
