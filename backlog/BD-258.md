Description:
  **Problem:** the large-BD/large-phase pipeline rule marks the researcher as "optional … per-need" and the adversarial+reconciliation bundle as "MINIMUM … OPTIONAL," and gates the reconciliation as "[if NEEDS-REWORK]." This reads as discretionary in places (it produced a live misread that "reconciliation is optional"). User direction 2026-06-30: for a LARGE BD/phase the flow MUST be deterministic — nothing optional or discretionary.
  **The deterministic LARGE flow (intent; architect designs exact phrasing per surface):**
    docs-researcher (ALWAYS first; internal census always + external-docs verification per-need) → architect → adversarial architect (ALWAYS) → reconciliation architect (IFF the adversarial found findings) → user design review → planner → adversarial planner (ALWAYS) → reconciliation planner (IFF findings) → user planner-to-coder gate → parallel worktree coder waves.
    The ONLY conditional stage is the reconciliation, and its skip is a LOGICAL CONSEQUENCE (no findings ⇒ nothing to reconcile), NOT a discretionary choice. The docs-researcher and both adversarial passes are UNCONDITIONAL for a LARGE BD.
  **Size-tiering KEPT:** the large-vs-small determination stays deterministic (by the existing size signals). Small/non-large BDs keep their lighter flow (UNCHANGED). A BD simply IS large or small; if large, the deterministic flow above is mandatory — the size test is deterministic, so "which flow" is never discretionary either.
  **Symmetry:** applied identically pack + project, trinity-symmetric on each side, with audience-correct vocabulary (BD pack-side; phase/TD project-side) per `cross-cli-reference-normalization`. No contradiction with `reconciliation-instance-independence` (a reconciliation, when it runs, is still a fresh independent instance).
  **Out of scope:** the small/non-large flow (unchanged); the size-signal criteria themselves (unchanged); BD-222's implementation.
  **Hard constraints:** trinity parity each side; pack-vs-project wording per `cross-cli-reference-normalization`; strip ALL "optional/discretionary" phrasing from the LARGE-flow description; follow the ordered propagation procedure (`PACK-CHAT.md` § "Keeping CLAUDE.md, AGENTS.md, GEMINI.md, and PACK-AGENTS.md current").
  **Acceptance criteria:** every pack + project pipeline-rule surface reworded to the deterministic large-flow (researcher-always-first, adversarial-always, reconciliation-only-if-findings); symmetric both sides; NO "optional/discretionary" language remains in the LARGE-flow description; trinity parity preserved (Check 18 etc.); `validate-pack` green.
