The vocabulary (the user's LEADING PROPOSAL — challengeable: per user direction 2026-07-04 the researcher and architect MUST challenge and improve these suggestions on evidence, not treat them as locked; the ordinal scale `current < next-patch < next-minor < next-major < future-unassigned`):
  - `current` — sometime before the current version is released.
  - `next-patch` — sometime after the current version is released but before the next patch, minor, or major version is released.
  - `next-minor` — sometime after the current version is released but before the next minor or major version is released.
  - `next-major` — sometime after the current version is released but before the major version is released.
  - `future-unassigned` — anytime; unconstrained and not release-blocking; may also carry a specific user comment about the version in the phase description text (human-only prose; tooling never interprets it).
  Targets are derivational metadata ONLY: they never change the mechanics of `Blockers`/`Unblocks`/dependencies (user-stated).
