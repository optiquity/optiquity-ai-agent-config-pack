# Xcode companion templates

Apple's Xcode 26.3 agent integrations are separate from your repo-level Claude and Codex CLI or IDE configs. Apple developers on the forums have referenced the following customization directories for agentic coding in Xcode:

- `~/Library/Developer/Xcode/CodingAssistant/codex`
- `~/Library/Developer/Xcode/CodingAssistant/ClaudeAgentConfig`

Treat these as user-local. Do not commit real copies of these into app repositories. Use the samples here as personal starting points. citeturn3search1
